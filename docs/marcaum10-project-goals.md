# Marcaum10 Project Goals

Source: `docs/marcaum10.md`

## Ultimate Goals

1. **Product goal:** Make Marcaum10 the control plane for long-running processes and agents, especially workflows that pause, wait, resume, route, and persist context across humans, services, webhooks, timeouts, and agents.

2. **Developer value goal:** Let teams avoid idle workers, polling loops, cron/status-table glue, and brittle custom orchestration by providing a durable lifecycle layer with explicit state, history, and resume mechanics.

3. **Business goal:** Validate that teams will pay for a developer-friendly platform that simplifies long-running process coordination.

4. **Near-term project goal for this repo:** Publish a credible landing page with sharp positioning, brand basics, waitlist capture, and enough product clarity to support validation and interviews.

5. **MVP goal:** Prove the core lifecycle primitives with design partners: process definitions, process instances, transition API, durable state/context, pause/resume, timeout scheduling, signals/events, process history, a lightweight dashboard, and one SDK/starter client.

## Strategic Read

This project is not just a landing page. The landing page is the validation front-end for a future developer platform whose real goal is durable pause/resume orchestration for async, human-in-the-loop, and agentic workflows.
